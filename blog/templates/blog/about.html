About This Blog

Welcome to Simple Blog — a minimal blogging and notes publishing platform built with Django. This project demonstrates the core building blocks of a Django web application: models, forms, function-based views, templates, and static/media file handling.

Anyone can create, view, edit, delete, and search blog posts — no login required. It's designed to be simple, clean, and beginner-friendly.
